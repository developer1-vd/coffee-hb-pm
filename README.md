# ☕ Coffee

Coffee is a simple graphical Homebrew package manager for Linux.

Because what is Homebrew without some Coffee?

Coffee provides a GTK interface for installing, uninstalling, upgrading, and managing Homebrew packages.

## Features

- Install Homebrew packages
- Uninstall packages
- Upgrade a selected package
- Upgrade all installed packages
- Update Homebrew
- Refresh the installed package list
- Search installed packages
- View live Homebrew command output
- Simple GTK4 interface
- Runs Homebrew commands without opening a terminal

## Requirements

- Linux
- Python 3
- GTK4
- PyGObject
- Homebrew for Linux
